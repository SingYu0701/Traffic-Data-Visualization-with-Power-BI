# Traffic-Data-Visualization-with-Power-BI
Final group report of Statistic Software &amp; Drawing, Jun 2023 @ NCKU Statistics

![Made with Power BI](https://img.shields.io/badge/Made%20with-Power%20BI-F2C811?logo=powerbi&logoColor=black)

## Overview

This project demonstrates the complete workflow of building an interactive data visualization dashboard using **Microsoft Power BI**, from data import and preprocessing to visual design and insight generation. The project was completed as a team-based course assignment.

The dashboard focuses on transforming raw data into intuitive visuals that support **data-driven understanding and communication**, rather than advanced programming or algorithm development.

---

## Motivation

In many real-world scenarios, decision-makers are not data scientists and do not interact with raw datasets directly. The motivation of this project is to:

- Practice converting raw data into meaningful business insights
- Learn how to design dashboards that are **clear, interactive, and decision-oriented**
-  Develop practical skills in Power BI that are directly applicable to industry roles such as data analyst, business analyst, and operations analyst

---

## Tools and Technologies

* **Microsoft Power BI Desktop**
* Built-in Power BI data transformation tools (Power Query)
* DAX (basic measures and aggregations)

> Note: This project emphasizes visualization and analytical thinking rather than custom programming code.

---

## Data Source

The dataset used in this project was collected and organized for educational purposes. It contains structured tabular data suitable for demonstrating:

* Aggregation and summarization
* Categorical comparison
* Geographic visualization
* Time-independent distribution analysis

All data was imported directly into Power BI and processed within the software environment.

## Visualizations and Insights

The dashboard provides several actionable insights, including:

* Overall distribution patterns across different categories
* Regional differences revealed through map-based visualization
* Relative proportions highlighted using donut and area charts
* High-level indicators summarized through card visuals

Interactive filters allow users to explore the data dynamically and focus on specific subsets of interest.

---

## Project Limitations

* The dataset size is limited and intended for **demonstration purposes**
* Advanced DAX modeling and automation were not the focus of this project
* Real-time data connections were not implemented

Despite these limitations, the project effectively demonstrates end-to-end dashboard development and visualization logic.
